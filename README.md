# ECO-EYE 드론 외벽 결함 분석 웹앱

이 프로그램은 Streamlit 기반입니다.

## 기능
- 일반 카메라 영상 + YOLO `best.pt` → 균열 탐지
- 열화상 영상 → HSV 색상 기반 고온/열 손실 의심 영역 탐지
- Bounding Box 결과 영상 생성
- 균열 증거 사진 저장
- 개별 CSV + 통합 CSV 생성
- 결과 ZIP 다운로드

## 설치

터미널에서 프로젝트 폴더로 이동한 뒤:

```bash
pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열립니다.

## 사용 순서

### 균열 분석
1. 외벽 실화상 영상을 업로드합니다.
2. 학습된 균열 탐지 모델 `best.pt`를 업로드합니다.
3. 분석 시작 버튼을 누릅니다.

### 열화상 분석
1. 열화상 영상을 업로드합니다.
2. 분석 시작 버튼을 누릅니다.

둘 다 한 번에 업로드하면 하나의 통합 리포트로 정리됩니다.

## 다른 사람에게 배포

GitHub 저장소에 `app.py`, `requirements.txt`를 올린 뒤
Streamlit Community Cloud에서 저장소를 연결하면 웹 링크 형태로 배포할 수 있습니다.

> 주의: `best.pt`가 크거나 비공개 모델인 경우 GitHub에 직접 올리지 말고
> 현재 앱처럼 사용자가 웹페이지에서 업로드하도록 두는 방식이 편리합니다.

## 현재 열화상 방식의 한계

현재 열화상 알고리즘은 '실제 온도값'을 읽는 것이 아니라,
영상에 표현된 빨강/주황/노랑 계열 색상을 고온 영역으로 판정합니다.

FLIR Lepton 3.5의 radiometric/raw 데이터에서 픽셀별 실제 온도를 읽을 수 있다면,
추후 `온도 > 기준값` 방식으로 교체하는 것이 더 정확합니다.
